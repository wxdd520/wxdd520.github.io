# 个人简历网站

一个简洁的单页简历网站，适合求职使用。

## 部署到 GitHub Pages（3 步）

### 1. 创建 GitHub 仓库

去 https://github.com/new 创建一个新仓库，仓库名填：
```
你的用户名.github.io
```
例如你的 GitHub 用户名是 `zhangsan`，就填 `zhangsan.github.io`

### 2. 上传文件

把 `index.html` 上传到这个仓库的根目录。

可以用 GitHub 网页直接上传：
- 打开仓库页面
- 点击 "Add file" → "Upload files"
- 拖入 `index.html`
- 点击 "Commit changes"

### 3. 开启 GitHub Pages

- 进入仓库 → Settings → Pages
- Source 选择 `main` 分支，目录选 `/ (root)`
- 点击 Save

等 1-2 分钟，访问 `https://你的用户名.github.io` 就能看到了！

---

## 如何编辑

直接用任何文本编辑器（记事本就行）打开 `index.html`，把里面占位的文字替换成你自己的信息。

需要改的内容：
- **标题**：搜索 `你的名字`，全部替换成真名
- **求职意向**：修改 `subtitle` 那行
- **联系方式**：邮箱、手机、GitHub、LinkedIn 链接
- **教育背景**：学校、专业、GPA、课程
- **实习经历**：公司、职位、具体做了什么
- **项目经历**：项目名、技术栈、描述
- **专业技能**：你掌握的技术

## 小技巧

- 每个经历尽量用**数字量化**：降低了多少、提升了多少、覆盖了多少
- 技能不要写太多，写你真正能聊的
- 项目 2-4 个就够了，质量 > 数量
